# Privacy Policy

**Last updated:** October 4, 2024

## Our Commitment

CodePulse is built with privacy at its core. We believe your code and data should remain yours, always.

## Desktop Application

The CodePulse desktop application is **completely offline** and makes **zero network requests**:

- ✅ All code analysis happens locally on your machine
- ✅ Your source code never leaves your computer
- ✅ No telemetry, analytics, or crash reporting
- ✅ No automatic update checks
- ✅ No data collection of any kind
- ✅ File system access is read-only and scoped to folders you explicitly select

**You can verify this**: The entire codebase is open source. Audit it yourself or build from source.

## Website & Download Analytics

When you visit our website or download CodePulse, we collect minimal anonymous statistics:

### What We Collect

- **Hashed IP Address**: We hash your IP with a random salt using SHA-256. This is impossible to reverse and is used only to prevent duplicate counting.
- **Geographic Region**: Country, region, and city (provided by our CDN)
- **Platform**: macOS, Windows, or Linux
- **Version**: Which version you downloaded
- **User Agent**: Browser information (to detect compatibility issues)
- **Referrer**: Where you came from (to understand how people find us)

### What We DON'T Collect

- ❌ Raw IP addresses (only hashed)
- ❌ Personal information
- ❌ Email addresses or accounts
- ❌ Tracking cookies
- ❌ Browsing behavior across sites
- ❌ Any data from the desktop app

### Why We Collect This

Download statistics help us:
- Understand which platforms need more attention
- Detect technical issues with specific versions
- Measure the project's reach and impact

**All data is aggregated and anonymous.** We never sell or share this data with third parties.

## Third-Party Services

We use the following services:

- **Vercel**: Website hosting and CDN (provides geographic headers)
- **Supabase**: Database for anonymous download statistics
- **GitHub**: Source code hosting and release distribution

Each service has its own privacy policy, but we've configured them to minimize data collection.

## Data Retention

Anonymous download statistics are retained indefinitely for analytical purposes. Since all data is hashed and aggregated, there's no way to link it back to individuals.
