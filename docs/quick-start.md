# 🚀 Démarrage Rapide - CodePulse

Lancez CodePulse en moins de 2 minutes.

## Installation

```bash
# 1. Cloner le projet
git clone https://github.com/AdlarX9/code-pulse.git
cd code-pulse

# 2. Configuration automatique
./codepulse.sh setup
```

## Lancement

### Application Desktop

```bash
./codepulse.sh desktop
```

### Application Web

```bash
./codepulse.sh web
```

### Les Deux Simultanément

```bash
./codepulse.sh dev
```

## Utilisation

### Application Desktop

1. **Sélectionner un dossier** à analyser
2. **Cliquer sur Scanner** pour lancer l'analyse
3. **Consulter les résultats** : statistiques, graphiques, répartition par langage
4. **Exporter** les données en CSV ou JSON

### Application Web

1. **Visiter** http://localhost:3000 (landing page)
2. **Accéder à `/admin`** pour le dashboard analytics
3. **Consulter** les statistiques de téléchargement et d'utilisation

## Commandes Utiles

```bash
./codepulse.sh help          # Aide complète
./codepulse.sh build         # Build toutes les apps
./codepulse.sh test          # Lancer les tests
./codepulse.sh clean         # Nettoyer le projet
./codepulse.sh release v1.0.0 # Créer une release
```
